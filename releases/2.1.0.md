# Obsek v2.1.0 — „Prawda i Bezpieczeństwo"

Etap 1 refaktoru v2.1 (E1.1–E1.8). Zero nowych feature'ów poza rdzeniem — za to plugin przestaje udawać: to, co obiecuje, naprawdę robi.

Najważniejsze:

- **Wyszukiwanie semantyczne NAPRAWDĘ działa.** Nowy VaultIndexer buduje indeks znaczeniowy vaulta (Orama) przy starcie, łapie zmiany na bieżąco i trzyma indeks na dysku (restart nie przelicza od nowa). Status i przycisk Re-indeksuj w Settings. Desktop-first; telefon dostaje uczciwy komunikat. Pamięci agentów i strefy No-Go są twardo wykluczone z indeksu.
- **Bezpieczeństwo fail-closed.** Agent z brakującą/zepsutą whitelistą dostaje minimalny zestaw narzędzi (nie wszystkie); sub-agent nie wykona narzędzia spoza przecięcia uprawnień żadną ścieżką; `web_read` pobiera tylko adresy znanego pochodzenia (wynik web_search albo link od Ciebie); `.pkm-assistant/` jest poza zasięgiem narzędzi vaulta; równoległe zapisy pamięci nie nadpisują się (kolejka per plik); XSS w ustawieniach modeli naprawiony; ostrzeżenie, gdy klucze API leżą niezaszyfrowane.
- **Kagańce.** Wszystkie limity agentów w jednym miejscu + edytowalne w Settings → „Limity". Pętla narzędzi ma prawdziwy hard-stop (ostatnia runda bez narzędzi — model musi odpowiedzieć tekstem). Wyniki narzędzi są przycinane, zanim wysadzą kontekst.
- **Plugin schudł z 8,35 MB do 3,0 MB** (wywałka js-tiktoken). Liczniki tokenów pokazują realne zużycie z API, a szacunki są uczciwie oznaczone jako „przybliżone" i kalibrują się same.
- **Komunikator uśpiony kill-switchem** na czas refaktoru (dane nietknięte, powrót = jedna flaga).
- **Wielkie wymiatanie:** martwy kod usunięty (Cohere, stare narzędzia, legacy formaty), ESLint pilnuje granic modułów, dokumentacja przeszła przegląd świeżości — mówi prawdę o stanie kodu.
- **Diagnostyka:** log pluginu do pliku (`.pkm-assistant/logs/obsek.log`) + komenda „Obsek: Self-test" z raportem stanu zdrowia.
